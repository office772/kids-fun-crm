# מכתב לתמיכת PayPlus — הגדרת דף תשלום לחידוש כרטיס בהוראת קבע

> להעתיק ולשלוח בצ'אט התמיכה של PayPlus.

---

שלום,

אנחנו עובדים מול ה-API שלכם ורוצים לאפשר ללקוחות **לעדכן את פרטי הכרטיס בהוראת קבע קיימת** (למשל כשכרטיס פג תוקף או הוחלף), בלי לפתוח הוראת קבע חדשה.

לשם כך אנחנו קוראים ל-endpoint:
`POST /api/v1.0/RecurringPayments/CreditCardRenewal/{recurring_uid}`
עם `disable_send_email: true`, כדי שיוחזר לנו קישור לדף תשלום שנשלח ללקוח (במקום מייל אוטומטי).

**הבעיה:** הקריאה מחזירה HTTP 200 אך עם שגיאה:
`results.code = 1`
`description = "default-payment-page-is-missing-for-renewal-email"`

מהבדיקות שלנו עולה שחסר במסוף **דף תשלום ברירת-מחדל לחידוש כרטיס**.

**הבקשה שלנו:**
1. נא להגדיר/לאפשר במסוף שלנו את **דף התשלום ברירת-המחדל לחידוש כרטיס** (renewal), כך שה-endpoint יחזיר קישור תקין.
2. נשמח להסבר כיצד מגדירים זאת בעצמנו בעתיד (איפה ההגדרה במערכת).
3. נבקש שזה יוגדר גם בסביבת הפרודקשן וגם בסביבת ה-sandbox (dev).
