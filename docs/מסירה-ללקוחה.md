# 🌟 Kids & Fun — מסירת המערכת לקורלי

מערכת ניהול הלקוחות + בוט הוואטסאפ מוכנה לשימוש. המסמך הזה מסכם את כל מה שצריך לדעת כדי להתחיל.

---

## 🔑 כניסה למערכת

**כתובת:** https://kids-fun-app-psi.vercel.app
מומלץ לשמור כסימנייה בדפדפן (גם בנייד). המערכת עובדת מכל מכשיר.

---

## 📚 שני מדריכים מובנים בתוך המערכת

1. **סיור אינטראקטיבי** — נפתח אוטומטית בכניסה הראשונה. בכל רגע אפשר לפתוח אותו שוב בלחיצה על כפתור ה־**?** הסגול (פינה תחתונה־שמאלית). הסיור מקפיץ אותך בין הלשוניות ומסביר כל אחת.
2. **מדריך שימוש מלא** — בפאנל הניהול (אייקון ההגדרות בתפריט) → הלשונית הראשונה **"מדריך שימוש"**. אקורדיון מסודר לפי נושאים, כולל פירוט **כל מסלולי הבוט**.

---

## 🤖 מה עובד אוטומטית (בלי שקורלי תעשה כלום)

- הבוט בוואטסאפ עונה להורים: רישום צהרון/קייטנה, ביטול, שעות, תשלומים, איסוף מוקדם, רשימת המתנה ושאלות כלליות.
- תשלומים מ-PayPlus ומחשבונית ירוקה נכנסים למערכת בזמן אמת.
- כשל תשלום → הבוט פונה להורה להסדרה, ונפתחת פנייה.
- רשימת נוכחות שבועית נשלחת במייל לצוות כל מסגרת.
- תזכורות והצעות מקום נשלחות בזמנן.

---

## ✅ מה שווה לעשות כדי לנצל הכול

1. **להזין מייל לצוותי המסגרות** — פאנל ניהול → צוותי צהרון / צוותי קייטנה. בלי זה, רשימת הנוכחות השבועית לא תישלח אוטומטית למסגרת.
2. **לעבור על תכני הבוט והשאלות-ותשובות** — לוודא שהנוסח מתאים (תוכן הבוט).
3. **לבדוק את הבוט בסימולטור** — פאנל ניהול → סימולטור בוט (בלי לשלוח הודעות אמיתיות).
