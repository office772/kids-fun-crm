# 🌟 Kids & Fun — מדריך ניהול לקורלי

מדריך פשוט לניהול המערכת מהדפדפן. אין צורך בידע טכני — הכול דרך לחיצות.

**כתובת המערכת:** https://kids-fun-app-psi.vercel.app
מומלץ לשמור כסימנייה (Bookmark) בדפדפן.

---

## 📊 לוח הבקרה (דשבורד)

בראש המסך יש תפריט עם הלשוניות. הנה מה יש בכל אחת:

### סקירה
המסך הראשי. רואים במבט מהיר:
- **התראות דחופות** (כשלי תשלום, תזכורות) — לחיצה על השורה פותחת/סוגרת את הרשימה.
- מספרים כלליים: הורים, פניות פתוחות, כשלי תשלום, שיחות היום.
- תצוגה מקוצרת של הפניות וההורים האחרונים.

### הורים
כל ההורים במערכת.
- **חיפוש** לפי שם הורה / שם ילד / טלפון.
- **סינון** (דרופדאונים): תשלום, מסגרת, אזור, מקור.
- לחיצה על הורה → כרטיס מלא עם פרטים, ילדים, תשלומים והיסטוריה.
- **ייצוא הורים / ייצוא תשלומים** → קובץ Excel.
- כפתור **"הורה חדש +"** להוספה ידנית.

### רישומים
רישומים לצהרון ולקייטנה — אישור, רשימת המתנה.
- כרטיסי סטטיסטיקה: מאושרים / ממתינים / רשימת המתנה / סה״כ.
- סינון לפי סטטוס וסוג, וייצוא ל-Excel.

### נוכחות 🆕
רשימות המשתתפים לפי מסגרת — לצפייה, ייצוא, ושליחה שבועית לצוות.
- **מתג למעלה:** 🎒 צהרון / ☀️ קייטנה.
- כל מסגרת היא שורה שנפתחת בלחיצה (אקורדיון) ומציגה: שם הילד/ה, כיתה, הורה, טלפון, מייל.
- **כפתור "ייצוא"** בכל מסגרת → Excel של אותה מסגרת.
- 📧 **שליחה שבועית אוטומטית:** פעם בשבוע כל מסגרת מקבלת במייל את רשימת המשתתפים שלה — **רק אם הזנת מייל לצוות שלה** (ראי "פאנל ניהול → צוותי מסגרות").

### פניות
פניות שנפתחו (כשלי תשלום, בקשות, תלונות וכו').
- סינון לפי סטטוס, חיפוש, מתג תצוגה כרטיסים/טבלה.
- בכל פנייה אפשר לשנות סטטוס: פתוח / בטיפול / טופל.

### ספקים · ארכיון
ספקים = אנשי קשר עסקיים. ארכיון = נתוני עבר.

### תוכן הבוט
עריכת מה שהבוט עונה בוואטסאפ. שלוש לשוניות:
- **תכני הודעות** — הודעות הבוט (ברכה, אישור רישום וכו'). אפשר לערוך, להוסיף, ולכבות/להפעיל כל הודעה.
- **שאלות ותשובות** — השאלות שהבוט עונה עליהן אוטומטית. הוסיפי מילות מפתח כדי שהבוט יזהה ניסוחים שונים.
- **הגדרות מערכת**.
- מתג תצוגה כרטיסים/טבלה למעלה.

### קבצים וקישורים
הקישורים והקבצים שהבוט שולח (טפסי רישום, PDF, תמונות, קישורי תשלום).
- כל פריט מקבל **מפתח** — לחיצה עליו מעתיקה אותו להדבקה בטקסטי הבוט.
- אפשר להעלות PDF/תמונה, לערוך URL, ולכבות/להפעיל.

## ⚙️ פאנל ניהול

נכנסים דרך אייקון ההגדרות בתפריט (או הכתובת `/admin`). כאן:

- **קיבולת אזורים** — כמה ילדים אפשר לרשום לכל אזור.
- **צוותי צהרון** / **צוותי קייטנה** — אנשי הצוות של כל מסגרת (רכזת, גננת...).
  👈 **חשוב:** כדי שרשימת הנוכחות תישלח אוטומטית במייל — צריך להזין כאן **מייל** לאיש צוות אחד לפחות בכל מסגרת.
- **סימולטור בוט** — לבדוק את הבוט בסביבה בטוחה, בדיוק כמו בוואטסאפ (כולל "איפוס פונה לבדיקה").
- **סנכרון נתונים** — ייבוא היסטורי מחשבונית ירוקה (חד-פעמי). PayPlus וחשבונית ירוקה ממילא מתעדכנים אוטומטית בזמן אמת.

---

## 🤖 מה קורה אוטומטית (בלי שתעשי כלום)

- **הבוט בוואטסאפ** עונה להורים: רישום, ביטול, שעות, תשלומים, איסוף מוקדם, רשימת המתנה ושאלות כלליות.
- **תשלומים** מ-PayPlus ומחשבונית ירוקה נכנסים למערכת אוטומטית.
- **כשל תשלום** → הבוט פונה להורה לעדכון, ונפתחת פנייה במערכת.
- **רשימת נוכחות שבועית** נשלחת לצוות המסגרות (עם מייל).
- **תזכורות והצעות מקום** נשלחות בזמנן.
